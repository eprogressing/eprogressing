## About

<p>

I'm a senior undergraduate in Computer Science at **Nankai University** and an incoming PhD student at **[NBJL](https://nbjl.nankai.edu.cn/)**.

My research interests are efficient systems for LLMs and embodied AI:

- **LLM inference systems** — execution efficiency and AI infrastructure.
- **GPU and heterogeneous computing** — performance optimization across hardware.
- **Embodied AI systems** — efficient infrastructure for embodied intelligence.

I also build tools and share learning resources through **[Lamplighter Commons](https://github.com/lamplighter-commons)**.

## Projects

### [Triangle Light Maze Solver](https://github.com/lamplighter-commons/triangle-light-maze-solver)

An interactive visualization of dynamic programming: build a triangular maze, mark its glowing nodes, and find the path that collects the most lights. Includes the DP table, path reconstruction, and tie-breaking rules.

**[Try the live demo](https://lamplighter-commons.github.io/triangle-light-maze-solver/)** / [Source code](https://github.com/lamplighter-commons/triangle-light-maze-solver)

`JavaScript` `HTML / CSS` `Dynamic programming` `MIT License`

Runs entirely in the browser, with no installation or build step. The application interface is currently in Chinese.
